Javier Rodriguez – Portfolio Project (Intro 26.2)
Portfolio project for the Intro to Programming course with Code the Dream.

This repository contains two main components:

Personal Portfolio Website

Weather API Page (Open API Project)

Both projects are built using HTML, CSS, and JavaScript, and demonstrate DOM manipulation, API integration, and clean UI design.

Portfolio Website
The portfolio includes:

Navigation between sections

Dynamic skills generated with JavaScript

GitHub API integration to display repositories

A message form that supports creating and deleting entries

A navigation link to the Open API Project page

Weather API – Open API Project
This page demonstrates how to retrieve and display data from a public API using JavaScript.
It fulfills all requirements of the Open API Rubric.

Features
Two separate API GET requests

Navigation buttons to switch between:

Temperature data

Weather condition data

Each button triggers a new GET request

Error handling for invalid cities or network issues

Clean and responsive UI

Files Used
open-api.html – HTML structure

css/open-api.css – Styling

js/open-api.js – API logic and DOM updates

Endpoints Used
Temperature Endpoint

Conditions Endpoint

Each endpoint is requested separately depending on the button clicked.

How to Run the Code
Portfolio Website
Download or clone the repository:

Code
git clone https://github.com/Javix202/Javier-Rodriguez-intro26.2
Open the project folder.

Open index.html in your browser.

Navigate through the portfolio sections.

Click "Open API" in the navigation bar to access the Weather API page.

Weather API Page (Open API Project)
Open open-api.html in your browser.

Enter a city name in the input field.

Click:

Temperature (fetches only temperature data)

Conditions (fetches only weather condition data)

Each button sends a separate GET request to the API.

Results appear dynamically on the page.

No server or installation is required. The project runs directly in the browser.
